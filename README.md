# منظومة القافلة — Al-Qafila System

A sophisticated Arabic RTL marketing landing page for **Al-Qafila System**, a digital sovereignty and specialized AI services company based in Damascus, Syria.

## Key Technologies

- **TanStack Start** (React 19, SSR)
- **Tailwind CSS v4** (Vite plugin)
- **Netlify Forms** for lead capture
- **Google Fonts** — Cairo & Tajawal (Arabic typefaces)
- **FontAwesome 6** for iconography

## Features

- Full Arabic RTL layout with custom dark gold theme
- Interactive ROI calculator (client-side React state)
- Simulated AI sales agent chatbot with predefined responses
- Lead capture form via Netlify Forms (AJAX submission, no page reload)
- Responsive design for mobile and desktop

## Running Locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

> Note: Netlify Forms submissions require a live Netlify deployment. Local form submissions will not be processed.

## Deployment

Push to your connected Git repository. Netlify will automatically build and deploy.
